Add an agent

The agent is registered on the machine you pick, runs that machine's CLI, and works in the project's folder there. The machine has the final say — it refuses anything its owner hasn't allowed. Have a hire manifest? Import hire… fills this dialog with it for review — nothing is created until you press Create agent.
