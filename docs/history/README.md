# History

Finished work, kept for context rather than reference.

- `*-PHASE-*-RESULT.md` — per-phase reports from the parallel AI streams
  (presence, triggers, browser, server). Each records what was built, the
  method taken, and what was rejected.
- `HANDOFF-*.md` — the briefs those streams worked from.
- `antigravity/` — design docs for the features built unattended. Audited in
  the root `FEATURE-AUDIT.md`; treat those as claims, not as current truth.
- `PLAN.md`, `M3-STATUS.md`, `M4-KICKOFF.md`, `UI-PHASES.md` — superseded
  planning documents.

**The living documents are in the repo root.** If something here contradicts
`CONTRACT.md` or `DECISIONS.md`, the root wins.
